# Sign Language Assistant

Assistive technology project that translates sign language into text and allows people with disabilities to control smart home devices using hand gestures.

## Project Goals

- Real-time sign language recognition → text
- Gesture-based smart home control
- Designed for people with hearing or mobility impairments

## Current Status

- Learning Python and Computer Vision
- Setting up the project structure
- Hardware: Raspberry Pi 5 + Camera Module 3 (planned)

## Technologies (planned)

- Python
- OpenCV
- MediaPipe
- Raspberry Pi 5
- Relay modules for home automation
